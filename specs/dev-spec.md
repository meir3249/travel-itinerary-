\# Comprehensive System Specification: Rome Travel Map MVP\### 1. Project Context \& Strict ConstraintsYou are an Expert Frontend Developer and Software Architect. Your task is to generate the complete codebase for a mobile-first, interactive travel map of Rome.\* \*\*Tech Stack:\*\* HTML5, CSS3, Vanilla JavaScript (ES6+), Leaflet.js (for map rendering), and OpenStreetMap tiles.\* \*\*Deployment:\*\* GitHub Pages (Static hosting).\* \*\*Strict Prohibitions:\*\* DO NOT use any build tools, bundlers, or frameworks (No Node.js, Webpack, Vite, React, Vue, or Tailwind). The codebase must execute directly in the browser.\* \*\*Architecture:\*\* You must strictly follow a modular ES6 architecture (``.\#### `style.css` (UI/UX Design Language)\* \*\*Theme:\*\* "Waze-style". Clean white/light-gray backgrounds, highly rounded corners (`border-radius: 16px`), soft and deep drop shadows (`box-shadow: 0 8px 16px rgba(0,0,0,0.1)`). No Dark Mode.\* \*\*RTL Map Fixes:\*\* Leaflet popups break in RTL. You must explicitly target `.leaflet-popup-content-wrapper` and `.leaflet-popup-content` to enforce `direction: rtl; text-align: right;` and reposition the close button to the left side.\#### `map.js` (Leaflet Controller)\* \*\*Auto-Fit Bounds:\*\* Upon receiving the parsed JSON array, calculate the geographical bounds of all points and trigger `map.fitBounds()` so the user immediately sees all locations.\* \*\*Singular Popup Rule:\*\* Ensure `map.closePopup()` logic dictates that opening a new marker completely dismisses any previously opened popup.\* \*\*Expose Methods:\*\* `initMap()`, `renderMarkers(data, activeFilters)`, `locateUser()`.\#### `ui.js` (DOM \& Event Management)\* \*\*Filter Menu (Hamburger):\*\* Positioned fixed at \*\*top-left\*\*. Tapping opens a clean modal/sidebar with checkboxes for each category.\* \*\*Real-Time Filtering:\*\* Changing a checkbox must instantly trigger `map.renderMarkers()` without requiring an "Apply" button.\* \*\*Locate Me Button:\*\* A floating action button (FAB) positioned fixed at \*\*bottom-left\*\*. Triggers the browser's Geolocation API and pans the map to the user's blue-dot location.\* \*\*Loader:\*\* A full-screen overlay with a CSS spinner. Must be removed from the DOM explicitly by `app.js` only after the map is fully loaded and markers are rendered.\### `config.js` (Central Configuration Module)The configuration must be implemented as a dedicated JavaScript file exporting a constant ES Module object (`export const CONFIG = { ... }`), allows synchronous immediate access across all modules, and permits code comments for future human maintainability.The structure must strictly follow a logical taxonomy. Use highly descriptive, human-readable keys:\*   \*\*`MapSettings`\*\*: Defines `defaultCenter` (Lat/Lng array), `initialZoom`, `minZoom`, `maxZoom`, and the `tileLayerUrl` (OSM).\*   \*\*`DOM\\\_Selectors`\*\*: A single source of truth for all HTML IDs and Classes used in `ui.js`. Do not hardcode strings like `'#filter-menu'` in logic files; reference `CONFIG.DOM\\\_Selectors.filterMenu`.\*   \*\*`CategoryStyles`\*\*: A dictionary where each key exactly matches the Hebrew category names from `places.json` (e.g., 'היסטוריה', 'פארק'). Each key must map to an object containing:&#x20;   \*   `hexColor`: The specific HEX code for the map marker (e.g., `#E63946`).&#x20;   \*   `iconClass`: The CSS class for the internal marker icon (e.g., FontAwesome string like `'fa-solid fa-monument'`).\#### `api.js` (Data Fetching)\* Contains a single asynchronous function `fetchPlaces()` that attempts to load `places.json`. Include robust `try/catch` error handling that logs errors to the console.\#### `app.js` (Orchestrator)\* Imports config, ui, map, and api modules.\* Initializes the map -> Fetches Data -> Renders Data -> Binds UI events -> Hides Loader -> Registers Service Worker.\#### `sw.js` (Service Worker for Offline PWA)\* Rome has severe network dead zones. The app MUST work 100% offline after the initial load.\* \*\*Install Event:\*\* Pre-cache `index.html`, `style.css`, all JS modules, Leaflet assets (CDN URLs), and most importantly, `places.json`.\* \*\*Fetch Event:\*\* Implement a `Cache First, fallback to Network` strategy for all static assets and the JSON file. Ensure the user can filter categories, tap markers, and view popups entirely in airplane mode.
